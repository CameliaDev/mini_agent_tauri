# `src-tauri/.gitignore`

- 源码：[`.gitignore`](./.gitignore)
- 分层：后端目录的忽略规则（模板自带）

## 职责

`create-tauri-app` 模板放在 `src-tauri/` 下的忽略规则，排除 Cargo 生成的 `/target/` 与 Tauri CLI 生成的 `/gen/schemas`。

本项目把 `/gen/schemas` 改成了 `/gen/schemas/*` 并加了 `!/gen/schemas/README.md`：JSON 仍是生成物不入库，但目录级说明文档要入库，否则仓库里的文档链接会指向不存在的文件。

## 与根 `.gitignore` 的关系

Git 的忽略规则按目录层级叠加：子目录的 `.gitignore` 优先于根目录同名规则。本项目把 `src-tauri/target/` 写在了[根规则](./../.gitignore.md)里（更集中、更好审计），所以这里的两份规则是**冗余但无害**的。

## 当前行为说明

- 根目录 [`.gitignore`](../.gitignore.md) 里的 `src-tauri/target/` 与这里的 `/target/` 是冗余但无害的双保险：Git 忽略规则按目录层级叠加，子目录规则优先。
- 想知道某文件到底被哪条规则忽略，用 `git check-ignore -v <路径>`，它会打印命中规则所在的文件与行号。
