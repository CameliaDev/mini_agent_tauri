# `Composer.tsx`

- 源码：[`Composer.tsx`](./Composer.tsx)
- 分层：前端展示层

## 职责

底部输入区：一张居中的卡片，里面是输入框、快捷键提示和发送按钮。

## 包含的定义

| 定义 | 作用 |
| --- | --- |
| `Composer()` | 组件本体 |

## 逻辑要点

1. 输入内容来自 store 的 `draft`，不是组件自己的 `useState`——这样空态示例按钮能往同一个输入框里塞字。
2. `submit()`：去掉首尾空格；空内容或正在生成都不发；先清空输入框再发请求。
3. `onKeyDown`：Enter 发送，Shift+Enter 换行（用 `preventDefault` 阻止默认换行）。
4. **生成中时按钮换成「停止」**：点一下调 `stopGeneration()`，后端会打断正在进行的网络读取；已收到的半截文字保留。
5. 生成中输入框**不锁定**（可以提前写下一句），但发送按钮被替换掉了，所以不会并发发起第二轮。
6. 没有内容时发送按钮禁用。

## 依赖关系

- 依赖：`../store`、`../ipc/chat` 的 `sendMessage` 与 `stopGeneration`。
- 被谁使用：`App.tsx`。

## 当前行为说明

- 「停止」是协作式取消：点下去后后端会在下一个检查点退出，不是立刻杀掉请求。
